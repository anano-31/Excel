# PROJECT 1 — Sales Performance Dashboard

## Scenario

You are a junior analyst at RetailCo. You receive monthly sales data for five regions. Your task is to build a compact dashboard that summarizes performance and highlights trends.


## Deliverables

1. Create a **KPI summary table** using `SUM`, `AVERAGE`, `MAX`, and `MIN` for each region.

2. Create a **region ranking** by annual total revenue.

3. Insert one chart:
   - A **line chart** showing monthly regional trends, or
   - A **column chart** comparing annual totals.
