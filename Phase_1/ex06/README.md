# Phase 1 / ex06 — Charts and Visualization

## Objective

Create clear visual summaries from structured revenue data.


## The Tools

Bar chart, Line chart, Pie chart, plus chart formatting options in Excel.

## Tasks

1. Create a **bar chart** comparing all four stores for **Q1** using **January, February, and March** data.

2. Create a **line chart** showing **Store A's** monthly revenue trend across the year.

3. Create a **pie chart** showing the **annual revenue share by store**.

4. Add **data labels** to the bar chart.

5. Change the chart title to a clear **business title** for each chart.
