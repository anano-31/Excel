# Phase 1 / ex03 — VLOOKUP

## Objective

Retrieve values from structured tables using an exact or approximate match.

## The Tools

`=VLOOKUP(lookup_value, table_array, col_index, [range_lookup])`


## Tasks

1. Find the salary for employee ID **E104**.

2. Return the department name for the code in employee row **E103**.

3. Use an approximate match to assign a salary band to **Liam's** salary.

4. Build a formula that returns **Mina's** department name by first finding her department code and then matching that code in the department table.

5. Return **Not Found** when an ID lookup fails.
