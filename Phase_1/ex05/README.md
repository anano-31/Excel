# Phase 1 / ex05 — Absolute and Mixed References

## Objective

Learn how to lock cell references, apply formulas across datasets, and understand when to use absolute and mixed references.


## The Tools

Absolute references using `$` (for example `=$B$2`), mixed references such as `$A1` and `A$1`


## Tasks

1. Calculate the price after tax for every product using the tax rate stored in cell **$B$2**.

2. Calculate the discounted price for every product using the discount rate stored in cell **$C$2**.

3. Calculate the final price after applying both tax and discount.

4. Explain why **B2** should be written as **$B$2** when copying formulas.

5. Build a **1-to-5 multiplication table** using mixed references, with multipliers across row 1 and down column A.
