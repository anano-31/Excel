# Phase 1 / ex04 — COUNT Family

## Objective

Count records, non-empty values, and criteria-based subsets.


## The Tools

`=COUNT()`, `=COUNTA()`, `=COUNTIF()`, `=COUNTIFS()`


## Tasks

1. Count how many numeric age entries exist.

2. Count how many non-empty names exist.

3. Count how many ratings are greater than or equal to **4**.

4. Count how many customers are from **London**.

5. Count how many customers are from **London** and purchased **Yes**.
